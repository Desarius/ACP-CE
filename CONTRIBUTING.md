# Contributing

ACP-CE is a proposed research program rather than a validated scientific result.

Open an issue or pull request for literature corrections, counterexamples, falsifiable hypotheses, controlled experiment designs, metrics, replication work or ethical critique.

Distinguish evidence from interpretation. Cite primary sources. Do not present an agent's self-description as proof of consciousness. Do not submit credentials, private data or unauthorized proprietary code.

The originating conceptual proposal is attributed to **Dario Visaggio "Desarius"**. Independent prior work and substantive future contributions should receive accurate, separate credit. Any authorship on new research outputs should reflect actual contributions.

The repository has no explicit reuse license yet. Do not assume that public availability supplies one.
